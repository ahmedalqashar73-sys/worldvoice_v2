# WorldVoice Library – original PDFs

This folder is reserved for the reviewed original illustrated PDFs. Keep the
names stable and include the original front cover, chapters and artwork.

- the_blue_envelope.pdf
- the_empty_house.pdf
- the_last_train.pdf
- the_red_umbrella.pdf
- daniel_carter.pdf

The PDF reader uses a bundled file at the matching path automatically. Until
the original PDF binary is supplied in this folder, the reader prompts for a
one-time import from the phone and stores it in application documents.

Do not replace these with reflowed HTML/Dart pages or text-only drafts.
Do not delete the chapter JSON: it is retained for future AI pronunciation.
